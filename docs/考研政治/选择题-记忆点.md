## 史纲 与 毛中特

革命派与维新派辩论的核心问题(焦点) {++要不要以革命手段推翻清政府的统治++}

同盟会成立后 {++第一次++}武装起义是萍浏醴起义, {++最大的一次++}是广州起义(黄花岗起义)

保路(铁路)风潮加速了革命的爆发

武昌起义拉开了{++中国完全意义上的近代民主革命的序幕++}, 是辛亥革命的{++高潮++}

{++中国民国临时约法++} 是中国{==第一部==}具有资产阶级共和国宪法性质的法典,从{++根本上废除了两千年的封建君主专制++}

孙中山挽救共和的努力 {++二次革命(反袁世凯)++}, {++组建中华革命党++}, {++护国运动++}, {++护法运动++}
- 史纲对孙中山只褒不贬, 凡是批判的选项均错误
- 资产阶级革命派的缺点不是孙中山的缺点

{++辛亥革命的失败原因++}

- 根本原因: 资本主义建国方案不行
- 主观原因: 资产阶级本身具有许多不足(根源于资产阶级的阶级局限性)
    - 未能提出{++彻底++}的反帝反封的革命纲领
    - 未能充分发挥人民群众
    - 不能建立坚定的革命政党


新文化运动的主要阵地 {++新青年杂志和北京大学++}, 基本口号 {++民主和科学++}

新文化批判孔学的目的 {++为了个中国发展资本主义扫清障碍++}

新文化运动的两个阶段

- {++五四之前++} 局限性
    - 根本上来说, 资产阶级民主主义不适合中国社会
    - 不可能根本改造由社会环境造成的国民性, 试图优先改造国民性是错误的
    - 使用的资本主义的方法,而不是马克思主义的方法
- {++五四运动之后++} 优点
    - 提倡马克思主义的民主和科学
    - 争取人民群众的解法
    - 人民群众的革命路线

五四运动的直接导火线{++巴黎和会上中国的外交失败++}

五四运动首先由学生罢课为主,之后以工人罢工为主, 这是{++工人阶级第一次以独立姿态登上历史舞台++}.

五四运动定性 是一场{++彻底的++}反帝反封建的爱国主义革命活动, 是一场{++伟大的革命运动++}, 是一场{++伟大的思想启蒙和新文化运动++}

五四运动式新民主主义革命的{++开端++}, 孕育了以{++爱国,进步,民主,科学++}位主要内容的伟大五四精神.核心是{++爱国主义++}

{++中国人民对帝国主义的认识++}

- 第一阶段, 表面的感性认识阶段 : 义和团的笼统排外
- 第二阶段, 进到理性认识阶段 : 从五四运动前后才开始的

{++民族意识觉醒++}

- 鸦片战争之后少数人开始觉醒
- 中日甲午海战失败后, 中国人才开始{++普遍++}民族意识的觉醒
- 维新派(戊戌变法)推动了中华民族的民族觉醒
- 五四运动{++第一次全面觉醒++}
- 抗日战争时期 中华儿女表现出了空前的民族觉醒和民族团结
- 改革开放 中国共产党的{++第一次伟大觉醒++}


{++李大钊++}在{++我的马克思主义观++}中首次比较系统的阐述了马克思主义, 标志着马克思主义在中国进入{++比较系统的++}传播阶段.

{++国民党一大++} 重新解释三民主义(新三民主义), 事实上确认了{++联俄,联共,扶助农工++}三大革命政策, {++标志着第一次国共合作的形成++}

{++新三民主义++}

- 民族: 突出反帝内容
- 民权: 民主权利应该为一般国民共有,不应该为少数人得私
- 民生: 提出了耕者有其田, 否定了封建土地剥削制度

{++五卅运动++} 是大革命的起点

{++大革命中的共产党++}

- 提出{++反对帝国主义,反对军阀++}的政治口号
- 国共合作的倡导者和统一战线的组织者 {--不是领导者--}
- 帮助和推动了国民革命军的建立

{++大革命失败的原因++}

- 客观上: 反革命力量强大, 资产阶级发生动摇, 蒋汪二人背叛革命
- 主观上: ({++根本原因++}) 不善于将马克思主义与中国实际相结合起来; 党内以陈独秀为首的右倾机会分子在党的领导机关中占据统治地位;共产国际瞎指挥
- 失败的标志 {++国共合作全面破裂++}, 失败的后果 {++工人运动转向低潮++}

{++大革命的意义++}

- 必须坚持马克思主义中国化
- 一定要争取无产阶级在革命中领导权
- 必须坚持武装斗争
- 必须解决农民土地问题

{++三湾改编++} 是建设无产阶级领导的新型人民军队的{==重要开端==}

{++井冈山根据地++}开辟了农村包围城市,武装夺取政权的新道路


### 中共会议总结 

{++中国一大++}

- 确定了中国共产党的名称
- 制定了第一个党的纲领, {++把实现共产主义++}作为党的最高理想
- 建党精神 {++坚持真理,坚持理想++} {++践行初心,担当使命++} {++不怕牺牲,英勇斗争++} {++对党忠诚,不负人民++}


{++中国二大++}

- 首次提出来{++反帝反封建++}的民主革命纲领, 为中国革命指明了方向
- 发动工农运动
    - 香港海源罢工, 京汉铁路罢工({++掀起了工人运动的第一次高潮++})
    - 萧山成立了{++第一个++}农民协会
    - 香港大罢工是{++持续时间最长的一次++}
- 首次提出{++党的统一战线++}的政策
- 第一次公开发表 中国共产党宣言
- 制定了第一步 中国共产党章程

{++中国大三++}

- 共产党以个人身份加入国民党, 以实现国共合作

{++1927年七月的政治局常委会++}

- 准备南昌起义, 准备秋收起义, 讨论大革命失败后的新方针

{++八七会议++}

- 确定了土地革命和武装斗争的方针
- 由{==大革命失败到土地革命兴起==}的历史转变
